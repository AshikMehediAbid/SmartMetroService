# Product Vision

SmartMetroService is a backend API for metro operations and passenger journeys. The implemented domain supports accounts, station and fare data, single-journey QR tickets, RapidPass journeys, wallet balances, online payments, gate scanning, and administrator fare settings.

The repository contains a .NET API and supporting layers, not a passenger-facing web or mobile client. The product's target market, operator, launch geography, passenger personas, service-level goals, and frontend behavior are **Confirm** items; Bangladesh-specific currency and AamarPay integration appear in the implementation but do not establish all market requirements.
