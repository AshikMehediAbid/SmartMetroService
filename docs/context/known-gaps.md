# Known gaps

Where the code on `master` does not yet meet the rules in `AGENTS.md` and `golden-principles.md`, found while
writing the harness (2026-10-31). Each gap is its own future issue. Until one is fixed:

- **Do not copy the pattern** into new code.
- **Do not fix it as a side effect** of an unrelated issue; file it (`create-issue`) and link it here.
- **Reviewers** report a gap only when a diff adds to it or touches the lines involved.

When an issue closes a gap, delete its row in the same PR and update the matching invariant in `invariants.md`.
"Severity" is the reviewer scale: Critical, High, Medium, Low. Rows marked *verify* were read in the code but not
demonstrated against a running stack.
