# Data model

SQL Server, EF Core code-first. The model snapshot
(`SmartMetroService.Storage/Migrations/MyApplicationDbContextModelSnapshot.cs`) and `MyApplicationDbContext` are the
source; this is a map, not a copy. Mapping is by EF conventions plus `OnModelCreating` for stations, tickets,
journeys and payments.

| Table | Entity | Key | Notable columns | Indexes / FKs |
| --- | --- | --- | --- | --- |
| `Users` | `User` | `Id` uniqueidentifier | `Email`, `PhoneNumber`, `HashedPassword` (BCrypt), `UserRole` int, `IsEmailVerified`, `KeycloakUserId` | none on e-mail/phone (G10) |
| `UserOtps` | `UserOTP` | `Id` int | `Email`, `Otp` (plain text), `Type`, `ExpiryDate`, `IsUsed` | — |
| `RefreshTokens` | `Token` | `Id` int | `UserId`, `TokenHash` (SHA-256 hex), `ExpiredAt`, `RevokedAt`, IPs | — |
| `Stations` | `Station` | `StationId` int | `StationName`, `StationLocation`, `Latitude`/`Longitude` float, `StationOrder`, `IsActive` | — |
| `StationDistances` | `StationDistance` | `Id` int | `FromStationId`, `ToStationId`, `Distance` float | FK from-station cascade; to-station no action |
| `Settings` | `Settings` | `Id` int | `UnitFare` int, `MinimumFare` int | one row expected |
| `UserWallets` | `UserWallet` | `Id` uniqueidentifier | `UserId` **nvarchar** (the user's Guid as text), `Balance` **float** | none on `UserId` (G6, G10) |
| `Tickets` | `Ticket` | `Id` uniqueidentifier | `UserId`, `FromStationId`, `ToStationId`, `Fare` int, `QRByte` varbinary, `TicketType`, `TicketStatus`, `ExpiryTime` | `UserId`, `TicketStatus`, `ExpiryTime`; station FKs no action |
| `Journeys` | `Journey` | `Id` int | `UserId`, `RapidPassId`, `TicketId` (shadow FK), stations, `Fare` int, `StartAt`, `EndAt`, `JourneyStatus` | `UserId`, `RapidPassId`, `JourneyStatus`, `StartAt`; RapidPass FK restrict |
| `Payments` | `Payment` | `Id` int | `UserId`, `UserEmail`, `MerTxnId`, `PgTxnId`, `BankTrxId`, `Amount` decimal(18,2), `Currency`, `Status` nvarchar, `PaymentFor`, `TicketType`, `TicketGenerated`, `PaidAt` | **unique** `MerTxnId`; `UserId` |
| `RapidPasses` | `RapidPass` | `Id` uniqueidentifier | `UserId`, `QRByte`, `ExpiryTime` | none on `UserId` (G10) |

`BaseEntity` adds `CreatedAt`, `UpdatedAt` (set from `DateTime.Now`, G8) and `IsDeleted`; nothing reads `IsDeleted`,
so deletes are hard deletes.

User-owned rows reference the user by `UserId` without a foreign key to `Users`. Ownership is enforced in queries, not
by the database: every query on these tables filters by the caller's user id.

## Migrations
Generated by `dotnet ef migrations add`, named `<timestamp>_<PascalCaseName>`, each with a `.Designer.cs`. Two
hand-written files are not real migrations (G9). Rules: `AGENTS.md` §8 *Data and migrations* and
`harness/workflows/ensure-migrations.md`.
