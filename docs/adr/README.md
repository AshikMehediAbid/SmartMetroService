# Architecture Decision Records

A decision that was contested, or that a later reader would otherwise undo, gets an ADR in the same PR as the code:
copy [`0000-template.md`](./0000-template.md) to `NNNN-<slug>.md` (next number, four digits), 20–40 lines, and add a
row below. A reversed decision is marked `superseded by NNNN`, never deleted.

Decisions made before the harness existed (layered projects, EF Core code-first on SQL Server, two token issuers,
Redis for RapidPass entries, AamarPay) are described in [`../context/architecture.md`](../context/architecture.md).
Write an ADR for one of them when it is changed or challenged.
